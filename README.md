# kinvas

kinvas is a browser-based viewer for KiCad schematics and PCB layouts. Open local files without uploading them, inspect board layers, replay layout progress, and export board graphics.

Try the [standalone app](https://nigh.github.io/kinvas/) or see the [documentation](https://nigh.github.io/kinvas/home/) for examples and embedding instructions.

## Development

Install dependencies with `npm ci`, then run `npm run serve` for local development. Use `npm run build` to build, `npm test` to run the browser tests, and `npm run lint` to check the code.
